 Hotel Saturno - Sistema de Reservas
 Aplicación web frontend desarrollada para la visualización y gestión de reservas hoteleras. Este proyecto permite a los usuarios explorar un catálogo de habitaciones, filtrar opciones mediante una búsqueda dinámica y procesar simulaciones de reservas con cálculo interactivo de estadías

 Funcionalidades Principales

Catálogo Dinámico: Renderizado de tarjetas de habitaciones con imágenes, categorías y precios, consumiendo datos desde un módulo local.
Buscador Integrado: Filtro en tiempo real que permite buscar habitaciones por nombre o categoría.
Gestión de Reservas: Vista detallada de la habitación seleccionada con un calculador interactivo de noches que actualiza el precio total estimado al instante.
Estado Interconectado: Barra de navegación superior que rastrea y refleja en tiempo real la cantidad de reservas confirmadas durante la sesión.
Diseño Responsivo: Interfaz adaptable a múltiples resoluciones (teléfonos, tablets y escritorio) mediante el uso de cuadrículas (Grid) y cajas flexibles (Flexbox).



Para ejecutar este proyecto en un entorno local, asegúrate de tener [Node.js](https://nodejs.org/) instalado en tu equipo y sigue estos pasos:

Clona el repositorio en tu máquina local.
Abre una terminal en el directorio raíz del proyecto.
Instala las dependencias necesarias ejecutando:
   bash
   npm install
   npm run dev
Abre la URL local generada en tu navegador (por defecto http://localhost:5173).
